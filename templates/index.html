    🔒 DPDP Act 2023 Trust Layer & Compliance

    NARMADA is engineered from ground up with the Digital Personal Data Protection (DPDP) Act, 2023 requirements:

    • Explicit Multilingual Consent: Voice audio is captured only after the user presses the speak action with clear purpose notice.
    • Data Minimization: Raw voice audio streams are processed in-memory. Only structured livelihood features (tools, experience, domain) are persisted.
    • Cryptographic Audit Trails: Every generated NSQF recommendation is sealed with an immutable SHA-256 hash containing timestamp, profile metadata, and cited Qualification Pack.
    • Human-in-the-Loop Oversight: State Skilling Officers have an auditable override and approval dashboard before any government grant is disbursed.
    • Right to Erasure: Citizens can clear their session and associated metadata at any time.
