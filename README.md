# NARMADA prototype
1. `pip install -r requirements.txt`
2. `cp .env.example .env` and set OPENAI_API_KEY and your Neon DATABASE_URL
3. `python app.py` then open http://localhost:5000 (Chrome/Edge for voice)
Tables and sample knowledge base (kb.json) are created on first run. kb.json holds SAMPLE entries: replace with real NSQF Qualification Packs and verified scheme rules.
